# Glossary

Alphabetical terms with chapter references.

- **Activity diagram** — Collaborative workflow with concurrency/swimlanes. (Ch07)
- **AIR** — Automatic, Independent, Repeatable. (Ch03)
- **Allowlist** — Explicit accepted values or destinations. (Ch04)
- **AO** — Application Object: reusable Service-related behavior. (Ch06)
- **API contract** — Defined input, output, protocol, and failure behavior. (Ch01)
- **AQS** — AbstractQueuedSynchronizer, queue-based synchronization foundation. (Ch01)
- **Atomicity** — Indivisibility of an operation under concurrent access. (Ch01)
- **BCDE** — Border, Correct, Design, Error test perspectives. (Ch03)
- **BigDecimal** — Decimal representation supporting explicit precision/scale semantics. (Ch01)
- **BO** — Business Object representing business-level semantics. (Ch06)
- **CAS** — Compare And Swap: atomic conditional memory update. (Ch01)
- **Checked exception** — Compile-time catch/declaration obligations apply. (Ch02)
- **Class diagram** — Model classes and their structural relationships. (Ch07)
- **Composition** — Extend behavior by collaborating objects rather than inheritance. (Ch07)
- **Covering index** — Query obtains required fields from index access. (Ch05)
- **CSRF** — Cross-site request forgery using authenticated browser state. (Ch04)
- **DAO** — Data Access Object handling persistence. (Ch06)
- **Deadlock** — Cyclic resource waits prevent progress. (Ch01)
- **Delayed association** — Locate narrow page keys before fetching wider rows. (Ch05)
- **Dependency inversion** — Depend on stable capability abstractions. (Ch07)
- **Dependency mediation** — Effective version selection across dependency paths. (Ch06)
- **Discrimination** — Distinct-value ratio used to evaluate index prefixes. (Ch05)
- **DO** — Data Object matching table structure. (Ch05, Ch06)
- **DRY** — Don't Repeat Yourself: maintain common knowledge in one place. (Ch07)
- **DTO** — Data Transfer Object crossing service boundaries. (Ch06)
- **Error code** — Five-character A/B/C-origin classification; success 00000. (Ch02)
- **Error message** — Diagnostic description carrying variable failure context. (Ch02)
- **EXPLAIN** — MySQL query-plan inspection. (Ch05)
- **File descriptor** — OS handle for resources such as files and sockets. (Ch06)
- **First-party library** — In-project module dependency. (Ch06)
- **Fixture** — Prepared test input/state with controlled lifecycle. (Ch03)
- **GAV** — Maven GroupId, ArtifactId, Version. (Ch06)
- **Guard clause** — Early exit separating an exceptional branch from normal flow. (Ch01)
- **Heap dump** — Memory snapshot used to diagnose allocation/retention failures. (Ch06)
- **Idempotence** — Repetition preserves intended single-effect semantics. (Ch04, Ch06)
- **Integration test** — Check of interactions across components/systems. (Ch03)
- **Leftmost prefix** — Useful initial composite-index portion. (Ch05)
- **Liskov substitution** — Subtype remains usable under its parent's contract. (Ch07)
- **Logging facade** — Backend-independent logging API. (Ch02)
- **Lost update** — Mutation overwrites another concurrent change. (Ch01)
- **Magic value** — Unnamed literal carrying business/configuration meaning. (Ch01)
- **Manager** — External-service adaptation and shared business infrastructure. (Ch06)
- **Mock** — Controlled collaborator substitute isolating the tested unit. (Ch03)
- **Nonfunctional requirement** — Quality constraint, e.g. security/availability. (Ch07)
- **NPE** — NullPointerException, including failures from null unboxing. (Ch01, Ch02)
- **OOM** — Out-of-memory condition, commonly java.lang.OutOfMemoryError. (Ch01, Ch06)
- **OOP** — Object Oriented Programming. (Ch01)
- **Open/closed principle** — Extend variation while preserving stable code. (Ch07)
- **Optimistic locking** — Version/expected-state conflict detection. (Ch01)
- **ORM** — Object-relational mapping. (Ch05)
- **PECS** — Producer Extends, Consumer Super. (Ch01)
- **Pessimistic locking** — Exclusion before protected-state validation/update. (Ch01)
- **POJO** — Manual-specific simple getter/setter/toString category including DO/DTO/BO/VO. (Ch01, Ch06)
- **Query** — Typed request object for inter-layer query criteria. (Ch06)
- **ReDoS** — Regex denial of service through expensive crafted input. (Ch04)
- **Replay** — Repeated action contrary to its intended operation contract. (Ch04)
- **Result** — Cross-boundary success/error envelope. (Ch02)
- **ResultMap** — Explicit database-column to object-property mapping. (Ch05)
- **Scale** — BigDecimal's decimal-place representation, considered by equals. (Ch01)
- **Second-party library** — Company-internal library shared across applications. (Ch06)
- **Sequence diagram** — Ordered object interactions with calls and data flow. (Ch07)
- **Single responsibility** — One coherent reason for change. (Ch07)
- **SNAPSHOT** — Mutable development version restricted in production. (Ch06)
- **SQL injection** — Untrusted data changes executable query structure. (Ch04, Ch05)
- **SSRF** — Server-side request forgery through unintended caller-controlled targets. (Ch04)
- **State diagram** — States, legal transitions, and their triggers. (Ch07)
- **SUT** — System under test with asserted behavior. (Ch03)
- **Third-party library** — External open-source library in the manual's terminology. (Ch06)
- **ThreadLocal** — Per-thread association requiring cleanup on reused threads. (Ch01)
- **Unchecked exception** — No compile-time catch/declaration obligation. (Ch02)
- **Unique index** — Database uniqueness enforcement. (Ch05)
- **Use-case diagram** — Actors and supported interactions. (Ch07)
- **User tip** — Safe actionable end-user failure explanation. (Ch02)
- **Variation point** — Isolated change axis. (Ch07)
- **View** — Collection interface sharing another container's backing storage. (Ch01)
- **Visibility** — Observability of published writes across threads. (Ch01)
- **VO** — View Object passed toward display/template rendering. (Ch06)
- **Volatile** — Visibility/ordering, not compound-operation atomicity. (Ch01)
- **Week-year** — Year assigned to a week rather than calendar date. (Ch01)
- **XSS** — User data interpreted as unwanted executable browser content. (Ch04)
